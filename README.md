# Al-Mustafeed (المستفيد)

Complete digital platform for **Al-Mustafeed**, an Islamic institution running a Tahfeez (Qur'an memorisation) programme.

## Project Structure

This repository contains two primary applications:

1. **`MANAGEMENT SYSTEM/`**
   - Private, secure, online-only Tahfeez Management System.
   - Built with **React 19**, **TypeScript**, **Tailwind CSS**, and **PWA** capabilities.
   - User Roles: **Developer (Dev)**, **Administrator (Admin)**, and **Teacher**.
   - Current status: **Login Page implemented** with client-side validation, demonstration authentication, role resolution, responsive Islamic design, and PWA manifest.

2. **`PUBLIC WEBSITE/`**
   - Public-facing informational website for Al-Mustafeed (Tahfeez programme, admission info, fees, gallery, contact details).
   - *To be developed in subsequent phases.*

## Tech Stack
- React 19
- TypeScript
- Tailwind CSS
- Lucide Icons
- Progressive Web App (PWA)
- Future Backend & Database integration

## Getting Started (Management System)
```bash
cd "MANAGEMENT SYSTEM"
npm install
npm run dev
```
